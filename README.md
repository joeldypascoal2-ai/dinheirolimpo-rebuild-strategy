# Dinheiro Limpo Audit & Plan

Quero iniciar uma reconstrução profissional do website do Dinheiro Limpo.

Website actual:
https://dinheirolimpo.com/

O projecto será desenvolvido no Lovable.

Este primeiro pedido é uma etapa de AUDITORIA, DESCOBERTA E PLANEAMENTO.

NÃO quero que reconstruas o website inteiro nesta etapa.

NÃO quero que alteres indiscriminadamente o design.

NÃO quero que substituas conteúdos existentes.

NÃO quero uma homepage nova ainda.

Primeiro quero que compreendas profundamente o produto digital que já existe, identifiques os problemas reais e prepares tecnicamente o projecto para uma reconstrução profissional.

O resultado final, nas próximas etapas, deverá parecer um website desenvolvido por uma equipa experiente de estratégia, UX/UI, copywriting e desenvolvimento web — e não um template gerado por IA.

==================================================
01. VISÃO DO PROJECTO

O Dinheiro Limpo é uma marca ligada à educação financeira, conteúdos, formação e desenvolvimento de conhecimento sobre dinheiro, investimentos, negócios e temas relacionados.

O novo website deve reforçar a percepção de:

credibilidade;

autoridade;

conhecimento;

confiança;

profissionalismo;

clareza;

educação;

proximidade;

organização;

maturidade institucional.

A evolução pretendida não é simplesmente estética.

Queremos transformar a experiência digital do Dinheiro Limpo numa presença institucional sólida, capaz de apresentar:

a marca;

a sua história;

o fundador;

a equipa;

os programas e cursos;

os conteúdos;

o podcast;

O website deve conseguir funcionar simultaneamente como:

vitrine dos programas;

mecanismo de conversão;

ponto de entrada para novos públicos;

demonstração de autoridade e confiança.

02. PRINCÍPIO CRIATIVO FUNDAMENTAL

Existe uma diferença importante entre:

"um website moderno"

e

"um website profissional".

Não quero perseguir tendências visuais apenas porque são populares.

Não quero que o resultado pareça uma landing page de uma startup de tecnologia.

Não quero estética de SaaS.

Não quero estética de fintech genérica.

Não quero excesso de glassmorphism.

Não quero gradientes decorativos sem função.

Não quero blobs abstractos.

Não quero excesso de cards flutuantes.

Não quero efeitos 3D desnecessários.

Não quero interfaces cheias de elementos arredondados apenas por tendência.

Não quero grandes quantidades de animação.

Não quero emojis como elementos de interface.

Não quero ilustrações genéricas de banco de imagens.

Não quero layouts que pareçam ter sido produzidos automaticamente por um gerador de websites.

Não quero sacrificar usabilidade em troca de "wow factor".

A direcção deverá ser:

INSTITUCIONAL
+
EDITORIAL
+
FINANCEIRA
+
HUMANA
+
CONTEMPORÂNEA
+
SÓBRIA
+
INTENCIONAL

O design deve parecer construído para o Dinheiro Limpo especificamente.

Cada elemento visual deve ter uma razão.

Se um efeito não melhora compreensão, hierarquia, navegação ou percepção da marca, não deve ser utilizado.

PRINCÍPIO:

"Não procurar parecer moderno. Procurar parecer credível, claro, humano e intencional."
